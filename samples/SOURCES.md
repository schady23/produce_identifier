# Public sample images

The original Banana.jpg, Granny-Smith.jpg, Green-Bell-Pepper.jpg, and Vine-Tomato.jpg images were downloaded from the [Grocery Store Dataset sample images](https://github.com/marcusklasson/GroceryStoreDataset/tree/master/sample_images/natural). Granny-Smith-crop.jpg is a crop of Granny-Smith.jpg using source rows 75:275 and columns 70:270 to isolate one foreground apple.

Dataset authors: Marcus Klasson, Cheng Zhang, and Hedvig Kjellstrom. Cite: “A Hierarchical Grocery Store Image Dataset with Visual and Semantic Labels,” WACV 2019. The source repository publishes an MIT license; the original license text is included here. These samples are demonstration inputs, not a training set or an accuracy benchmark.

Official model checkpoints: https://github.com/ultralytics/assets/releases/tag/v8.3.0 . Ultralytics licensing is described at https://www.ultralytics.com/license . Bundled DejaVu fonts retain their license in assets/fonts/LICENSE_DEJAVU.
